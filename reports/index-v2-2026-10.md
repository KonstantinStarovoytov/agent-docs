# Index v2 (October 2026): BM25 IDF, excludes, reference chunking, product filter

A side index, `agent_docs_hybrid_v2` (+ `_pages`), built 2026-10-12 next to
production `agent_docs_hybrid_v1`, which was not touched. Measured without
Cohere (quota exhausted until November): recall-in-pool only, using
`uv run python -m evals.diagnose_retrieval recall --out X.json [--product-filter]`
with `QDRANT_HYBRID_COLLECTION` set to the collection under test. Raw data in
`reports/index-v2/`.

## What changed

1. **BM25 IDF.** fastembed's `Qdrant/bm25` sends term frequencies only; Qdrant
   adds IDF only when the sparse vector has `modifier=IDF`. v1 was created by
   langchain-qdrant without it. `ensure_hybrid_collection` (src/ingestion/ingest.py)
   now creates the collection explicitly (dense `""` 1536 cosine, sparse
   `langchain-sparse` with IDF) before anything is added; reindex and
   index_hybrid both use it, and langchain-qdrant reuses the collection.
2. **Excludes and allows** (src/ingestion/sources.py), table below.
3. **Reference chunking.** Split on `####` too (new `h4` metadata, included in the
   Section prefix), and long Markdown tables (> 12 rows) become chunks of 12
   rows that repeat the header row. Table cell padding is collapsed.
   `CHUNKER_VERSION = "3-h4-and-table-rows"`.
4. **Product filter for answers.** `ask_docs(product=...)` and REST `/ask`
   `{"product": ...}` map to a vendor filter that reaches `search_hybrid`, the
   multi-query path and the iterative path. Dense retrieval rejects a filter.
5. Side fix: index metadata (`agent_docs_meta`) is now one point per
   collection, so building v2 did not relabel production's index date. The
   service still reads the old single point when its own is missing.

## What the data says

- **The index changes do not move recall in the pool.** The same groups are lost
  in v1 and v2. The misses are not caused by BM25 weighting, junk pages or long
  reference chunks.
- **Pre-rerank ranking got slightly worse in v2** (reciprocal rank −0.01 to −0.06).
  With small, entry-level chunks, a reference page now has more chunks competing,
  and IDF lifts rare tokens. Whether the reranker cares cannot be checked until
  Cohere is back; that check decides v2.
- **The product filter is the only change that recovers evidence:** one more
  coverage group at pool 10 and one at pool 40, plus retrieval-v3 at pool 40.
- Datasets are small (one group = 0.03 of coverage); full-corpus and
  query-transform are at the ceiling.
