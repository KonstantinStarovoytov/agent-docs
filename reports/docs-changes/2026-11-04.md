- **cursor › Models And Pricing** — <https://cursor.com/docs/models-and-pricing.md>
  The Cursor Token Rate exemption now covers third-party models priced below $0.10 per million cache-read tokens across all tiers, including when using your own API key.

- **cursor › Opentelemetry Export** — <https://cursor.com/docs/enterprise/opentelemetry-export.md>

  _+ Local agent conversations, 47 lines_
