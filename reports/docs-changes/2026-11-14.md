## Changed significantly (9)
- **claude-code › Use Claude Code in VS Code** — <https://code.claude.com/docs/en/vs-code.md>

  _+ Extended thinking in subagents, 103 lines_

  _+ Audit artifact activity with the Compliance API, − Review the audit log, 4 lines_
- **claude-code › Error reference** — <https://code.claude.com/docs/en/errors.md>
  The error reference adds troubleshooting links for more failure messages, clarifies usage-credit spend-limit errors, and documents higher retry-delay limits.

- **claude-code › Create a mod** — <https://code.claude.com/docs/en/plugins/mods/create.md>
  Mods can load without approval in `auto` or `bypassPermissions` mode and when resuming sessions, while the page clarifies when approval is required or mods can’t load.
  _+ Sessions that load a mod without asking, 18 lines_

- **claude-code › Tools reference** — <https://code.claude.com/docs/en/tools-reference.md>
  You can now set `CLAUDE_CODE_PERFORCE_MODE=1` to prevent editing read-only Perforce files until Claude runs `p4 edit`.
  _+ Protect read-only files in Perforce, 6 lines_
- **cursor › Endpoints** — <https://cursor.com/docs/cloud-agent/api/endpoints.md>
